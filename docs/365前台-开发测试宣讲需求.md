# 365 前台 · 开发测试宣讲需求

**对照站点：** https://gogame-test.sldaops.com/（Juan365 / Bingo365 测试前台）  
**原型目录：** `365-frontend-prototype/`（PC `c-end/` · H5 `h5/`）  
**原则：** 按线上前台路由与交互一比一还原可点逻辑；演示数据不得写成可对账口径。

---

## 一、需求背景与目标

### 背景

项目库已有抽奖、萌宠、后台等切片原型，缺少一套把 **365 前台整站路径** 串起来的可点稿。测试站 `gogame-test.sldaops.com` 是 Vue SPA，主题色 `#f26839` / `#fa9d1a`，覆盖大厅、分类、优惠、VIP、代理、账户、充提、合规弹窗。宣讲和联调需要一份不依赖测试环境账号、可离线点的 UI 原型。

### 路径 / 权限 / 联通

| 项 | 说明 |
|---|---|
| 前台入口 | PC：`/c-end/#/home`；H5：`/h5/#/home`。对照站根路径 `/` 进大厅。 |
| 后台入口 | 本项目不做后台。活动配置仍走既有 `qq-lottery-prototype/admin`、全站后台走 `qq-admin-prototype`。 |
| 谁能进 | 未登录可看大厅、分类、优惠列表、VIP 介绍、关于/条款；登录后才能进账户、充提、绑卡、KYC、每日任务、抽奖、消息、流水。 |
| 谁不能进 | 合规弹窗点 Exit → IP 限制页；维护页全站降级为公告 + 客服。 |
| 联通 | 大厅侧栏瓷片 ↔ 返水 / 红包雨 / 代理 / 转盘 / 每日任务；优惠卡 ↔ 活动详情 ↔ 对应玩法页；账户 ↔ 充提 / 消息 / 流水 / 限额 / 改绑；H5 与 PC 共用 `juan365_frontend_v1`。 |

### 目标

1. 宣讲时能按线上走法点完：未登录 → 合规 → 登录 → 大厅分类 → 进游戏（演示桌）→ 充值 → 提现 PIN → 优惠领取 → VIP / 代理。  
2. 开发 / 测试能按本文六段对路由、门槛、状态、异常打勾。  
3. 演示会员在各页一致，金额两位小数，时间 `YYYY-MM-DD HH:mm:ss`。

### 业务要求

- **做：** 前台壳、路由、登录门槛、余额展示、充提演示、优惠领取、代理转出门槛、合规弹窗、维护 / IP 页、H5 底栏。  
- **不做：** 真实支付、真实进厅、正式数仓、后台配置、宠物 / 抽奖后台编辑器（已有独立仓库）。  
- **硬约束：** Toast / 文案标明演示；不得把假流水写成可对账口径；21+ / PAGCOR 限制文案保留。

## 二、详细功能说明

### 2.1 大厅 Home / Lobby

1. **功能名称：** 大厅  
2. **功能说明：** 前台默认页。Banner、公告条、分类 Tab、热门 / 精选游戏、厂商条。  
3. **展示规则：** 未登录 / 已登录都进 `#/home`。分类固定：Lobby、Bonus、Slot、Bingo、Perya、Casino、Sports、Card、Arcade、Fishing、Numeric（与线上 `home-nav` 一致，Card 不是 Poker）。Banner 4 帧：首存 50%、周返水、红包雨、代理。公告红字滚动 Responsible Gaming。游戏卡至少 8 张热门 + 16 张精选，带 HOT / NEW / BONUS 角标。维护游戏叠 `UNDER MAINTENANCE`。  
4. **交互逻辑：** 点 Banner 切下一帧并改圆点。点分类 Tab 高亮并过滤。点 Lobby 恢复热门 / 精选 / 厂商。点厂商只显示该厂商。点游戏：维护则 Toast；未登录弹登录；已登录开演示桌并写入 Recently。点 Search 开搜索层，少于 3 字提示，满 3 字过滤。  
5. **业务规则：** 不扣余额。Recently 最多 8 个、去重置顶。  
6. **状态说明：** 默认 Lobby；骨架屏由预览条切换；空分类显示 No record。  
7. **延伸：** 分类也可走 `#/category/:name`；厂商也可走 `#/game-platform`。

### 2.2 顶栏与侧栏壳

1. **功能名称：** Header / Sidebar / Footer / 浮标  
2. **功能说明：** 全站共用壳。  
3. **展示规则：** Logo `JUAN365` + `JUAN365.COM`。未登录：Login + Sign Up。已登录：现金金币、奖金铜币、刷新、Deposit、头像首字母、消息红点、客服。侧栏未登录瓷片：8% Cashback / Money Rain / Affiliate / Lucky Spin / Rebate。已登录：Daily Cashback 金额、Money Rain、Affiliate、Lucky Spin、Daily Tasks。底栏 Games / About / Info / Responsible Gaming + 支付品牌。右侧浮标 ₱36.5 Sign-up、Money Like Rain。  
4. **交互逻辑：** Login / Sign Up 开登录层。Deposit、头像、消息走对应 hash，未登录先登录。刷新 Toast「Balance refreshed (demo)」。客服开 Live Chat。语言 English / Tagalog（界面仍英文，Toast 提示）。Copy 类按钮写剪贴板并 Toast。  
5. **业务规则：** 余额来自本地 store，充提 / 领取后回写。未读消息数驱动红点。  
6. **状态说明：** 登录态由预览条或登录成功切换；掉线 Alert 会清登录。  
7. **延伸：** H5 无侧栏，底栏 Home / Promos / 中心充值 / VIP / Account。

### 2.3 登录 / 注册 / 合规

1. **功能名称：** 登录注册与 Responsible Gaming  
2. **功能说明：** 首次进站合规层；登录需勾选条款。  
3. **展示规则：** 未看过合规：PAGCOR 21+ 禁止清单（未满 21、公职、AFP/PNP、NDRP、GEL）。登录层左侧首存海报，右侧 Phone、条款勾选、Login、Password / Facebook / Google、法律灰框。未勾选点 Login 出 Reminder。  
4. **交互逻辑：** Accept 关闭合规并记 `seenRg`。Exit 去 IP 限制页。Accept Terms 勾上复选框。Login 成功写 `loggedIn`、进大厅并刷新壳。预览条可强制出合规 / Alert。  
5. **业务规则：** 演示手机默认 `096930983098`，不校验运营商。不接短信。条款未勾不能登录。  
6. **状态说明：** 默认未登录；成功已登录；Alert 掉线；Reminder 拦截。  
7. **延伸：** 改密走 `#/account/changeLoginPassword`；忘记密码文案在改密页。

### 2.4 搜索与进游戏

1. **功能名称：** 搜索 / 演示桌  
2. **功能说明：** 按游戏名或厂商搜；进厅用演示桌代替真实 iframe。  
3. **展示规则：** 搜索层标题 Search，提示至少 3 个字符，默认 Respected 8 款。演示桌展示游戏名、厂商、当前现金、Back to lobby。  
4. **交互逻辑：** 输入即时过滤；无结果 No record。维护游戏不可进。  
5. **业务规则：** 不产生注单。Recently 写入 store。  
6. **状态说明：** 默认推荐；搜索中；空；维护。  
7. **延伸：** `#/recently` 只读最近玩过。

### 2.5 优惠中心与活动详情

## 三、流程图 / 交互说明

### 主路径（宣讲）

```text
打开 /c-end/
  → 合规弹窗 Accept
  → 点 Sign Up / Login → 勾条款 → Login
  → 大厅切 Slot / Casino → 点游戏进演示桌 → Back
  → Deposit 选 GCash ₱ 1,000.00 → 入账回账户
  → Withdraw 填 ₱ 200.00 → PIN → 流水待审核
  → Promotions → 活动详情 → Daily Tasks 领取
  → VIP 看权益 → Affiliate 看推荐人
  → 预览条切未登录 / 维护 / IP
```

### 分支

| 分支 | 走法 | 回到 |
|---|---|---|
| 未勾条款 | Reminder → Accept / Cancel | 登录层 |
| 合规 Exit | IP 限制 | 客服或改预览态 |
| 未登录点充提 / 任务 | 登录层 | 原目标 hash |
| 游戏维护 | Toast | 大厅 |
| 代理转出 &lt; 1000 | Toast | Panel |
| 提现余额不足 | Toast | 提现页 |
| 搜索 &lt; 3 字 | 提示 | 搜索层 |
| H5 底栏 Deposit | `#/deposit` | 账户 |

### 回页

Logo / Home Tab 回大厅。账户子页 crumb 回 Account。活动 Join now 回对应玩法。演示桌 Back 关层留在当前页。

## 四、异常场景

| 异常场景 | 触发条件 | 用户感知 | 系统处理 | 是否可重试 | 备注 |
|---|---|---|---|---|---|
| 接口失败 / 超时 | 原型无接口 | Toast「demo」类提示 | 不改余额 | 是 | 正式环境应对失败码 |

## 六、风险预估

### R1 演示入账被当成可对账

1. **是什么：** 原型充提 / 领取会改本地余额并写流水。  
2. **影响：** 资金口径被误用于对账或客诉。  
3. **出问题后怎么处理：** 页脚与 Toast 标明 demo；宣讲口头声明。  
4. **降级：** 预览条一键未登录；`localStorage.removeItem('juan365_frontend_v1')` 重置。

### R2 登录态与测试站不同步

1. **是什么：** 原型不读测试站 cookie。  
2. **影响：** 对照验收时「线上已登录、原型未登录」造成误判。  
3. **出问题后怎么处理：** 用预览条切已登录，对照同一会员号。  
4. **降级：** 只比路由与文案，不比会话。

### R3 抽奖 / 红包完整循环被本页简化

1. **是什么：** 本仓库抽奖只做入口级，完整循环在 `qq-lottery-prototype`。  
2. **影响：** 业务以为前台已含分享任务强制弹窗。  
3. **出问题后怎么处理：** 宣讲指向抽奖仓库；本文 2.7 已写边界。  
4. **降级：** 活动详情 Join now 可链到抽奖原型。

### R4 提现演示无真实审核

1. **是什么：** 提交后直接「待审核」，不会自动成功 / 拒绝。  
2. **影响：** 测试以为漏了审核流。  
3. **出问题后怎么处理：** 用预置流水里的「已结算 / 审核拒绝」讲状态。  
4. **降级：** 不在本原型做审核台。

### R5 第三方厅不可用

1. **是什么：** 无真实启动。  
2. **影响：** 进厅验收不能用本原型代替。  
3. **出问题后怎么处理：** 演示桌 + 维护遮罩表达状态。  
4. **降级：** 链到测试站（需账号）。

### R6 合规文案与牌照

1. **是什么：** 复制 PAGCOR / 21+ 限制清单。  
2. **影响：** 若正式文案变更，原型过期。  
3. **出问题后怎么处理：** 以测试站实时弹窗为准改文案。  
4. **降级：** 预览条可反复打开合规层对照。

### R7 本地存储被清

1. **是什么：** 清站点数据后余额 / 已领状态丢失。  
2. **影响：** 宣讲中途状态断。  
3. **出问题后怎么处理：** 刷新回 seed 会员。  
4. **降级：** README 写清 key。
